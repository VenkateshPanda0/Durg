# 2026-11-18: Repository structure, architecture and next steps

Request: scan the whole project and fix the system architecture description, the
TODO list, the steps to follow and the overall structure, so that anyone can
follow them.

## What the scan found

- No document described the system **as built**: the README's architecture
  diagram is the target design and shows services that do not exist yet.
- The README's expected self-test count (110) and its dated "local validation"
  block were stale; the observed count is 113.
- `crates/syscall` documentation pointed to a private file that is not in the
  repository, and still described the call table as three calls.
- `docs/README.md` indexed only part of the documentation (no book, design,
  reviews, devlog, requirements or checklist).
- The roadmap's first "next task" (hosted CI for the untyped-range hardening) was
  already done.
- `CHANGELOG.md` had an empty "Unreleased" section, with 21 commits since the
  `v0.1.0-alpha.1` tag.
- Getting-started instructions were split between the README, a WSL section and
  the quickstart, with different command lists.

## What changed

- New `docs/ARCHITECTURE.md`: layout, build-to-boot pipeline, boot sequence,
  kernel subsystems and lock order, the virtual memory map, the system-call and
  `invoke` interface with error codes, capabilities, IPC and notifications, and
  the test layers. Every address and constant was checked against the source.
- New `docs/TODO.md`: the ordered next tasks with where each lives and how to tell
  it is done (M10 completion first, the M18 decisions in parallel, then M11), plus
  first-contribution tasks linked to the open issues, housekeeping and known debts.
- `docs/contributor-quickstart.md` rewritten as ten steps from a clean machine to
  a pull request, with expected output and troubleshooting.
- `docs/README.md` rewritten as a reading order and a complete map.
- READMEs for `kernel/`, `crates/` and `user/`.
- README: a "Get started" section pointing at the guide, a repository layout table,
  the target design labelled as such, current counts.
- Roadmap "next tasks" now points at `TODO.md`; CHANGELOG "Unreleased" filled in;
  CONTRIBUTING and `AGENTS.md` point at the architecture page and the TODO list.
- The syscall crate's module documentation corrected (comment only, no code change).
